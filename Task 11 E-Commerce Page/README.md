# E-Commerce Page

## Task

Create an E-commerce page that allows users to browse, select, and purchase products from different categories.

The page should have the following features:

1. A filter menu that lets users choose from four categories:

    * Electronics
    * Clothing
    * Books
    * Automobile Accessories

2. An **Add to Cart** button for each product that adds the product to the user's shopping cart.

3. A **Remove from Cart** button for each product that removes the product from the user's shopping cart.

4. A **Total Amount** section that shows the sum of the prices of the products in the user's shopping cart and updates dynamically as products are added or removed.

## Notes

* Please use **Bootstrap** to style the page.
* You do not need to create a complex UI; a basic interface that meets the requirements is sufficient.
* You can use any **two to three products** of your choice for each category.
* No need for pagination or detail pages.
